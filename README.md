# Liquid Assets

Liquid Assets is a personal drinks log, laid out as a bar: a top shelf of categories, shelves of bottles below it, and a page for every drink and every maker. It is published as a static site at https://justin9598.github.io/Liquid-Assets/ and is built from a private ledger and private photos that are not in this repository; see `plans/` for the design and `build/` for the build script.
