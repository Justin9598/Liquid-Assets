# Plan 17: A real map in chalkboard style (MapLibre and OpenFreeMap)

Status: **Approved by the owner (2026-11-23): "Approve, build it".** D1 to D6 are confirmed as recommended. The owner first asked for MapLibre with Protomaps, then changed the tile source (2026-11-23): "use OpenFreeMap, update the plan". No push without the owner's word.

## 1. Brief

- **Today:** the Makers map and the maker-page map (Plan 14) are SVG drawings made from Natural Earth outlines by `build/tools/makemaps.py`. They show countries and provinces, a few hand-added towns, and no roads, rivers or fine coastline. Zooming jumps between fixed levels.
- **The change:** use a real, smoothly zooming map of the world, drawn by **MapLibre GL JS** in our own style, so it looks like chalk on the bar's slate:
  - dark slate land and a slightly darker sea;
  - chalk-white coastlines and borders;
  - faint chalk rivers and roads as you zoom in;
  - town names in chalk.
- **The data:** OpenStreetMap, served as vector tiles by **OpenFreeMap**.
  - It needs no account and no key.
  - It's a free, community-run service, funded by donations.
- **What stays the same:**
  - the drill-down (World → continent → region → country → area → province → maker);
  - the category-coloured pins and stack pins;
  - hatched provinces with makers;
  - the wooden place sign;
  - the legend, the info line and the two-way filter with the list;
  - the 8% framing rule, with nothing cut off (Plan 14 §13 and commit `7559f94`).
- **Fallback:** today's SVG map stays as the fallback. The page uses it whenever the real map can't run (§8).

- **No owner sign-up or key is needed.**

## 3. Libraries and files

| Piece | Choice |
|---|---|
| Map library | **MapLibre GL JS**: an exact version at least two weeks old, **self-hosted** in `docs/assets/vendor/maplibre-gl/` (JS, CSS and LICENSE), not loaded from a CDN |
| Loading | Loaded **only** on the Makers page and maker pages, on first use, as a dynamic import, so the welcome and drink pages stay as light as now |
| Tiles | **OpenFreeMap vector tiles** in the OpenMapTiles schema. Take the source URL from OpenFreeMap's own published style JSON (for example its dark style). Don't hard-code a guessed URL. Write it once into `content/map-config.json` as `tileSource`. |
| Basemap style | Generated by a build tool, `build/tools/makestyle.py`, into `docs/assets/maps/chalk-style.json`. Start from OpenFreeMap's dark style's layer list (OpenMapTiles layer names: `water`, `waterway`, `boundary`, `transportation`, `place` and so on), then recolour it to §4. **Every colour comes from the site's tokens.** |
| Fonts for basemap labels | The glyphs OpenFreeMap serves (Noto Sans family), with the URL taken from its style JSON, tinted chalk. Kalam isn't available as map glyphs without a Node tool (D3). |
| Our own overlay data | `makemaps.py` additionally writes **GeoJSON in longitude/latitude** for the outlines we already draw: `docs/assets/maps/geo/world.geojson` (countries with makers) and `geo/<country>.geojson` (provinces). It uses the same simplification, drops and maker-island rules as now. The existing SVG map files stay for the fallback. |

**Credits:** show "© OpenStreetMap contributors · OpenFreeMap · OpenMapTiles · MapLibre" in a small chalk attribution in the map's corner, as their licences require, and add them to the footer credit line.

## 4. The chalkboard style

All values are drawn from `app.css` tokens: `--slate #262a28`, `--iron #1f1c1a`, `--chalk #f2ede4`, `--glow #f4c27a`.

| Layer (OpenMapTiles) | Look |
|---|---|
| Background (land) | `--slate` |
| `water` (sea and lakes) | `--iron`, slightly darker than land. A faint 1 px shoreline line at 15% chalk. |
| Coastline (the edge of `water`) | Chalk, 1.1 px at z0–4 rising to 1.6 px at z8, 85% opacity |
| `boundary`, admin level 2 (countries) | Chalk, 1.2 px, 70%. Disputed or maritime boundaries are off. |
| `boundary`, admin level 4 (provinces and states) | Chalk, 0.8 px, dashed 3/2, 35%, from z4 |
| `waterway` (rivers) | Chalk, 0.6–1.2 px, 25%, from z6 |
| `transportation` | Motorways and trunk roads from z6 at 20% chalk. Primary and secondary roads from z9 at 14%. Minor roads only from z12 at 10%. Rail is off. |
| `building`, `landuse`, `landcover`, `poi`, `aeroway` | **Off.** Parks (`landcover` / `park`) are allowed at z12+ as a 4% chalk wash. |
| `place` labels | Countries, z2–6, in chalk at 80% with a slate halo. Cities and towns in chalk at 75%, by rank as zoom grows. Labels use English names (`name:en`), falling back to `name`. |
| Grain | The site's `--chalk-grain` noise as a CSS overlay above the map canvas, at about 6%, with `pointer-events: none`. This makes it read as chalk, not a flat vector map. |

## 5. Our layers on top

| Layer | How it's drawn |
|---|---|
| **Countries and provinces with makers** | A fill layer from our GeoJSON with a **hatch pattern** (a 6 px diagonal `--glow` line image, added with `map.addImage`), at 35% opacity. The selected province gets a heavier `--glow` outline (2 px) and a stronger hatch. Its neighbours are dimmed with a 50% slate wash, as in Plan 14 §13.1. |
| **Maker pins, group pins and stack pins** | **HTML markers** built with the existing `pinArt` SVG and CSS, so they look identical to today's. They keep their counts, category colours, fan-out on tap, focus outlines and `aria-label`s. |
| **Pin name tags** | HTML, in Kalam, as now. The existing `relax()` collision step runs on screen positions after each `moveend`. |
| **The capital** (maker page) | HTML label in Kalam, starred. The basemap's own town labels cover the other towns. The hand list in `map-places.json` stays, for the fallback and to mark capitals. |
| **The place sign, legend and info line** | Unchanged (HTML around the map). |

## 6. Levels and movement

- **Level changes:** each drill-down level does a **`fitBounds`** to the chosen place's outline, using the same rules as Plan 14 §13.2 and the region fix in commit `7559f94`. It animates smoothly (about 700 ms, eased), instead of jumping.
- **Moving freely:** the visitor may also **pan and pinch-zoom freely** (D2).
  - **On phones:** `cooperativeGestures` is on, so one finger scrolls the page and two fingers move the map, with MapLibre's hint shown in Kalam.
  - **On desktop:** scroll-zoom needs Ctrl or ⌘, with the same hint.
- **The breadcrumb** always shows the drill-down level, not the free view. Panning away doesn't change the level.
- **Reset button:** a small chalk button in the map's corner returns to the level's frame. It appears after the visitor has moved the map.
- **World level:** no repeated worlds (`renderWorldCopies: false`). Zoom is clamped between z1 and z15, or OpenFreeMap's top zoom if that's lower. **Fiji** is handled across 180° by the GeoJSON.
- **Maker page:** opens framed to the province (Plan 14 §6 rules). The maker's pin and the starred capital show, and towns come from the basemap.

## 7. The address and the filters

There's no change to how a place is kept in the address (`#/makers?at=…`) or to the map and list filtering each other. Free panning doesn't write to the address.

## 8. Falling back to the SVG map

The page uses today's SVG map (`map.js`, unchanged) when any of these is true:
- the browser has no WebGL;
- the tiles or style fail: a source error, or the map hasn't fired `load` within 8 s;
- the address has `?map=svg` (for testing and comparing).

The switch is silent for visitors. In the browser console it logs one line saying why. Because OpenFreeMap has no uptime guarantee, this fallback is the safety net, not an extra.

## 9. Build and checks

- **Build:**
  - `makemaps.py` writes the GeoJSON (§3).
  - `makestyle.py` writes the style.
  - **E10:** the style may use only colours from the token list.
  - **W31:** `map-config.json` has no `tileSource`. A warning, not an error, because the fallback covers it.
- **Smoke checks:**
  - Run the map smoke twice, once with the real map and once with `?map=svg`.
  - **Headless Edge** needs software WebGL (SwiftShader) flags. If the real map can't run headless, the smoke checks that the fallback appears, and real-map screenshots come from the browser pane instead.
  - **Real-map checks:** at each level, every pinned country's outline (minus dropped parts) and every pin are inside the frame, as in commit `7559f94`. The hatch layer is present, and the attribution is visible.
- **Weight:** report the downloaded size of the Makers page before and after, with the map library and the first tiles. The welcome page must not grow.

## 11. Decisions

| # | Question | Recommendation |
|---|---|---|
| D1 | Basemap | **OpenFreeMap vector tiles** (the owner's choice), with no account and no key. MapLibre is self-hosted. |
| D2 | Free pan and zoom on top of the drill-down? | **Yes,** with two-finger and modifier-key gestures and a reset button. Without it, the real map would add little. |
| D3 | Map labels in Kalam? | **Not now.** Basemap labels use OpenFreeMap's Noto glyphs tinted chalk, and **our** labels (places, capital, pins) stay in Kalam. Kalam map glyphs need a Node tool on this computer; that can be a later step if wanted. |
| D4 | Keep the SVG map? | **Yes,** as the fallback (§8). It's essential, because OpenFreeMap has no uptime guarantee. |
